# Green Pledge

A carbon offset platform that helps companies offset their carbon footprint through tree planting initiatives across India.

## Features

- 🌳 Interactive deforestation tracking dashboard
- 📦 Carbon credit packages from various locations
- 🗺️ Interactive map to select reforestation areas
- 🤖 GreenGuard AI Assistant powered by Google Gemini for environmental guidance

## GreenGuard AI Assistant

**GreenGuard** is your AI environmental assistant that helps you:
- 🌱 Learn about carbon offset packages and pricing
- 📊 Understand dashboard metrics and statistics
- 🗺️ Explore reforestation locations across India
- 🌳 Get information about different tree species
- 💰 Understand pricing tiers and investment options
- 📈 Track ESG goals and sustainability progress

### AI Assistant Setup

The AI Assistant uses Google Gemini for intelligent, conversational responses. The system is pre-loaded with comprehensive project knowledge including:
- Dashboard data (trees planted, CO₂ offset, ESG metrics)
- Available carbon credit packages
- Project locations across India
- Tree species information
- Pricing tiers and benefits

No additional API key configuration is required - GreenGuard is ready to use out of the box!

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
